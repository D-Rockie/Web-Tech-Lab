# Blog / Post Management App — React + Express + MongoDB Atlas

Full-stack REST API assignment for the Web Technology lab.

**Flow:** React frontend → `fetch()` → Express REST API → MongoDB Atlas

Setup instructions: see **[SETUP.md](SETUP.md)**.

## Structure

```
project/
├── app/                          React frontend (Vite)
│   ├── index.html
│   ├── vite.config.js            proxies /posts to the API on :5050
│   └── src/
│       ├── main.jsx              mounts App inside BrowserRouter
│       ├── App.jsx               nav bar + routes
│       ├── api.js                every fetch() call to the REST API
│       ├── index.css
│       ├── components/
│       │   └── PostSummary.jsx   one post card in a list
│       └── pages/
│           ├── Home.jsx          list all posts            (GET)
│           ├── Create.jsx        new post form             (POST)
│           ├── Post.jsx          read / edit / delete      (GET, PATCH, DELETE)
│           └── Archive.jsx       archived posts            (GET ?archived=1)
│
└── server/                       Express REST API
    ├── .env                      ATLAS_URI, DB_NAME, PORT  (not committed)
    ├── .env.example              template to copy
    ├── loadEnvironment.mjs       loads .env before anything reads it
    ├── index.mjs                 express app, middleware, mounts /posts
    ├── db/
    │   └── conn.mjs              single MongoClient for the whole app
    └── routes/
        └── posts.mjs             all five endpoints
```

## API

| Method | Endpoint | Body | Purpose |
|---|---|---|---|
| GET | `/posts` | — | All active posts, newest first |
| GET | `/posts?archived=1` | — | Archived posts only |
| GET | `/posts/:id` | — | One post |
| POST | `/posts` | `{ title, author, body, tags }` | Create |
| PATCH | `/posts/:id` | any subset of the fields, or `{ archived }` | Update |
| DELETE | `/posts/:id` | — | Delete |

Status codes: `200` OK · `201` created · `400` validation or bad id · `404` not found · `500` server error.

## Document shape

```js
{
  _id:       ObjectId,   // generated by MongoDB
  title:     String,
  author:    String,
  body:      String,
  tags:      [String],
  archived:  Boolean,    // soft delete — Archive page reads this
  createdAt: Date,
  updatedAt: Date
}
```

## Run it

```bash
# terminal 1
cd server && npm install && npm run dev     # http://localhost:5050

# terminal 2
cd app && npm install && npm run dev        # http://localhost:5173
```

`server/.env` must exist first — copy `.env.example` and paste your own Atlas connection string.
